## 📖 About

CANCERVIVE is a Final Year Project developed for the Bachelor of Information Technology (Hons.) at Universiti Teknologi MARA (UiTM).

The project integrates **Data Visualization**, **Machine Learning**, and **Interactive Dashboard Development** to assist doctors and oncologists in understanding cancer survival trends, predicting patient survival rates, and recommending suitable treatment options.

The dashboard allows users to analyse cancer survival data by different patient characteristics and provides prediction results using trained machine learning models.

---

## 🎯 Objectives

- Design an interactive dashboard for cancer survival analysis.
- Predict cancer survival rate using Machine Learning.
- Recommend suitable treatment based on patient characteristics.
- Visualize cancer survival trends using interactive charts.
